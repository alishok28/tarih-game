# Тарих Race KZ

Қазақстан тарихы бойынша бәйге мен викторина ойыны.

- Ойын: https://alishok28.github.io/tarih-game/
- Админ беті: https://alishok28.github.io/tarih-game/admin.html

## Құрылымы

| Файл | Не үшін |
|---|---|
| `index.html`, `js/game.js`, `css/game.css` | Ойынның өзі |
| `js/data.js` | Дәуірлер мен сұрақтар базасы (150 сұрақ) |
| `admin.html`, `js/admin.js`, `css/admin.css` | Админ беті: логин, 2FA, нәтижелер |
| `js/config.js` | Supabase мекенжайы және ашық (publishable) кілт |
| `supabase/security.sql` | Базаның қауіпсіздік ережелері |
| `vendor/`, `fonts/` | three.js, supabase-js және шрифттер (сайттың өзінде сақталады) |

## Сұрақтарды өзгерту

`js/data.js` ішінде әр сұрақ: `['Сұрақ', 'Дұрыс жауап', 'Қате 1', 'Қате 2', 'Қате 3']`.
Дұрыс жауап әрқашан екінші орында тұрады, ойын нұсқаларды өзі араластырады.
Әр жарыста дәуірдің сұрақтарынан кездейсоқ 5 сұрақ таңдалады.

## Қауіпсіздік

- Ойыншы тек нәтиже жібере алады: ешкімнің нәтижесін оқи, өзгерте немесе өшіре алмайды.
- Нәтижелерді тек бір админ оқиды, онда да құпиясөз және телефондағы 2FA кодымен кіргеннен кейін.
- Ұпайды сервер есептейді, мәндердің шегі тексеріледі, бір желіден келетін спам шектеледі.
- Сайт сыртқы скрипт, шрифт немесе сервис жүктемейді (Supabase-тен басқа); қатаң CSP қосулы.
- Репозиторийде ешқандай құпия кілт жоқ. `secret` / `service_role` кілтін ешқашан осында қоймаңыз.
